# Privacy Policy

Sports Digest processes user-selected sports, names, search terms, date windows,
and public article URLs. Avoid supplying private or unnecessary sensitive data.
The AIsa API key is supplied through Dify's provider credential store.

Requests are sent over HTTPS to `https://api.aisa.one` to obtain search results
and public article excerpts. AIsa may route requests to its search and extraction
providers. Those services and Dify may retain request data according to their
respective policies and workspace settings. See the [AIsa Privacy
Policy](https://aisa.one/legal/privacy-policy) for AIsa's practices.

The plugin does not use persistent Dify storage, tracking cookies, advertising,
or telemetry. It does not intentionally write inputs, API keys, or results to
disk. Results include public source metadata for use in a briefing. A standard
User-Agent identifies the plugin name and version to AIsa.

Removing the plugin or its credentials prevents future requests. Contact the
Dify workspace administrator about workspace logs and AIsa about service-side
data requests. Privacy questions: [developer@aisa.one](mailto:developer@aisa.one).
