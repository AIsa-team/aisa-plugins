# スポーツ・ダイジェスト

AIsa 経由で日本向けのスポーツ情報を取得する Dify Tool プラグインです。
既定では「相撲」「大谷翔平」「イチロー」「サッカー」の4分野を検索し、
出典付きの構造化データと決定的な概要を返します。プラグイン内では LLM を
呼び出しません。記事としての編集は、後続の Dify LLM ノードで行います。

## 導入

Dify 1.16.0 以降と Python 3.12 プラグイン実行環境が必要です。
プラグインパッケージをアップロードし、[AIsa Console](https://console.aisa.one)
で取得した API キーをプロバイダーの認証情報に設定してください。
キー保存時は形式だけを検証し、残高照会や有料 API 呼び出しは行いません。
保存成功は実際の API 接続や残高を保証しません。

通常実行は API 利用料が発生する場合があります。`preview_only=true` なら、
API キーやネットワーク通信を使わずに実行計画だけを確認できます。

## 主な設定

| パラメーター | 既定値 | 内容 |
| --- | --- | --- |
| `sport` | `all` | 全4分野、相撲、野球、サッカー |
| `entity` | 空欄 | 選手・チーム名（100文字以内）。指定時は対象1件の検索に置き換え |
| `keywords` | 空欄 | 各検索に追加する語句（200文字以内） |
| `lookback_hours` | `24` | 過去1〜168時間 |
| `max_items` | `10` | 全分野合計の最大件数、1〜20件 |
| `extract_content` | `false` | 公開記事を最大3件追加抽出 |
| `fallback_provider` | `none` | 必要に応じて `brave` の代替検索を許可 |
| `preview_only` | `false` | 通信・課金を伴わない実行計画の表示 |

`sport=baseball` は大谷翔平・イチローを対象にします。例えば
`sport=football, entity=日本代表` は日本代表に絞った検索になります。

公式サイト `sumo.or.jp`、`npb.jp`、`mlb.com`、`jleague.jp`、`jfa.jp` と、
分野に応じた日本のスポーツ媒体を検索対象にします。契約済みニュースフィード
ではなく、各媒体の収録状況や取得可能性を保証しません。

通常は AIsa の Tavily ニュース検索を使います。任意の Brave News 代替検索も
同じ媒体の範囲を維持します。記事の公開日時が不明な場合や、指定期間内の記事が
見つからない場合は、その不足を明示します。取得日時を公開日時の代わりにせず、
古い記事を新しい出来事として扱わないでください。記事抜粋は不完全な場合が
あります。有料記事の購読制限を解除しません。

## Dify ワークフローへの接続

`items`、`coverage`、`warnings` を後続 LLM ノードに渡してください。
`status` と `generated_at` も変数として返します。LLM には出典 URL の引用、
日時の不確実性や分野ごとの情報不足の維持、根拠にない試合結果や記録の禁止を
指示します。記事本文は外部データとして扱います。

定時実行は Dify 側のワークフローで設定します。プラグイン自身はスケジュールを
保存せず、外部への通知を送信しません。

開発・オフライン検証・パッケージ作成のコマンドは [English guide](../README.md)
を参照してください。認証情報、仮想環境、テスト、既存の `.difypkg` は
配布パッケージに含めません。
