# AIsa Trending Topics

An independent Dify tool plugin for Japan's current X topics, recent Japanese posts, and related YouTube videos. The installable plugin source is in [`dify/`](dify/).

The plugin gathers attributed evidence and deterministic Markdown. Connect its structured output to a Dify LLM node to produce a Japanese editorial summary.

See [plugin setup](dify/README.md) and the [testing guide](dify/TESTING.md). This package does not share a runtime with other packages in the collection.

Source: [package source](https://github.com/AIsa-team/aisa-plugins/tree/main/packages/trending-topics).
