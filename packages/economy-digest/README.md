# Economy Digest for Dify

An independently installable Dify tool plugin for Japanese economic news from
Nikkei. It retrieves source-backed evidence through AIsa for a downstream Dify
model to summarize.

Native plugin/provider/tool name: `economy-digest`; version: `0.1.0`.

See [the plugin guide](dify/README.md) for installation, parameters, offline checks,
and packaging. Japanese documentation is in [Japanese guide](dify/readme/README_ja_JP.md).
The runtime, dependencies, and release are independent of the other digest plugins.

Source: [package source](https://github.com/AIsa-team/aisa-plugins/tree/main/packages/economy-digest).
Support: [developer@aisa.one](mailto:developer@aisa.one).
